Fill `YOUR.URL` from [04-tweets.md](04-tweets.md). Screenshot every original post.

## Next morning (the actual launch)

Do these even if night-of underperformed.

| Order | Tweet |
|---|---|
| 1 | T5 “This is starting to get crazy” + full-board screenshot |
| 2 | T5 “built last night, N visitors, $X in 12 hours” |
| 3 | T6 any-rank $1 + “#5 is still $Y” |
| 4 | T4 tag whoever is #1 if they’re known |
| 5 | T8 directories ask |

Then rotate T4 / T5 / T7 all day.

Post a new original screenshot when **any** of these fire:

- #1 changes
- Round number: 1k visitors, $100 top bid, 10 listings, $1k bid, 100 entries
- A named person appears or gets knocked off
- You ship a 1-line money feature
- Outage, clone DM, buy-the-site DM, click-count proof

During a fight, cluster 2–3 tweets in a few minutes (traffic → new #1 → buy inbound). That’s an inning. Call it live.
